# Shopsphere - MERN Stack E-commerce Platform

## Project Overview

Shopsphere is a comprehensive, industry-level e-commerce platform built using the MERN stack (MongoDB, Express, React, Node.js). It offers separate interfaces for regular shoppers and administrators to manage the online store effectively.

## Key Features

**Dual Interfaces:**
- **Shopper Interface:** Allows users to browse products, view details, submit reviews, manage their cart, proceed through checkout, manage their account information and addresses, and view order history.
- **Admin Panel:** Provides administrators with functionalities to manage products (add, including image uploads via Cloudinary), track and update order statuses.

**Product Management:**
- Administrators can easily add new products to the catalog.
- Image uploads are seamlessly handled through Cloudinary integration.

**Product Browse:**
- Users can view the entire product catalog.
- Filtering options are available based on product category and brand.
- Sorting capabilities allow users to arrange products according to their preferences.

**Product Details & Reviews:**
- Detailed product pages provide comprehensive information about each item.
- Registered users who have purchased a product can submit reviews to share their experiences.

**Shopping Cart & Checkout:**
- Standard shopping cart functionality enables users to collect desired items.
- A streamlined checkout process includes address management.
- Secure payment processing is integrated via PayPal.

**User Account Management:**
- Users can manage their personal information and saved addresses.
- A history of past orders is readily accessible to users.

**Order Management (Admin):**
- Administrators have a dedicated interface to track the progress of customer orders.
- Order statuses can be updated as needed.

**Search Functionality:**
- A global search feature allows users to find products quickly by searching across titles, descriptions, categories, and brands.

## Technology Stack

- **Front-end:**
    - React
    - Redux Toolkit (for state management)
    - Tailwind CSS (for styling)
    - Shadcn UI (for UI components)
- **Back-end:**
    - Node.js
    - Express (for building the API)
- **Database:**
    - MongoDB
- **Third-party Integrations:**
    - Cloudinary (for image hosting)
    - PayPal (for payment processing)
